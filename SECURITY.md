# Seguridad

Se soporta la última versión publicada. El HTML se sanea y se muestra aislado; el proceso principal limita los archivos a la carpeta del curso. Abre materiales externos solo si confías en su procedencia.

Para comunicar una vulnerabilidad utiliza **Security → Report a vulnerability** en GitHub. Evita publicar datos sensibles o instrucciones de explotación en un issue público. Los errores funcionales pueden informarse en Issues.
